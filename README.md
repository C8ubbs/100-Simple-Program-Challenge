# 100-Simple-Program-Challenge
100 different exercises to improve your programming skill

I believe that in order for someone to be great at programming he/she must practice how to code. 
But in order to practice there should be challenges that test his/hers critical think and problem solving skills.
This repository is a simple project of mine to help improve my programming skills. 
Within this repo is a compilation of 100 simple python programs that you can use to practice how to code. 
I challenge anyone who would do this simple program challenge to beat the time I finished this project and show the simplest way to solve each program. 
I hope you enjoy!
